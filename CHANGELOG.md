# Changelog

## 0.1.0 - 2026-04-25

Initial GitHub-ready release generated for a 3-node adjustable Wazuh HA cluster project.

### Added

- MIT license.
- Main README and 20 localized README files.
- Ansible roles for preflight, config generation, distribution, indexer install, manager install, dashboard install, load balancing, repository locking, verification, and uninstall.
- 3-node converged and separated enterprise inventory examples.
- HAProxy, NGINX, and Keepalived templates.
- Support matrix for requested Linux distributions.
- Operations, installation, architecture, offline, troubleshooting, and references documentation.
